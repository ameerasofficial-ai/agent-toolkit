# Sanctions Screening

Screen names against official sanctions and export-control lists:

- **US Consolidated Screening List** (data.trade.gov): OFAC SDN and non-SDN lists, Commerce Entity List, and more
- **UN Security Council Consolidated List**

Fuzzy matching catches spelling variants and transliterations. Each result shows `overall` (clear / possible_match / match), `highest_score` and the matching list entries.

Lists are refreshed automatically every few days. If a list is temporarily unavailable, the name is **not charged**.

> This is a screening aid, not legal advice. Review possible matches manually.

## Pricing
One **name-screened** event per name successfully screened.
